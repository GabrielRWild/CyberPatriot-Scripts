# How To Use:

To run the linux scripts here download the code as a zip by clicking the green code button on the main screen of the repository.
Then unzip the zip file.
Navigate the terminal to get to the directory where the scripts use the command "ls" to list all the files in the current dir.
And "cd" to change the current dir. to another.  
Then user the command and tag "chmod +x CP.sh" to grant the main script run privileges"
Then simply type "sudo ./CP.ch" and watch those points rack up!
